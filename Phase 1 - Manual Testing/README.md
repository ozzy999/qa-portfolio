# Fase 1 — Manual Testing Fundamentals

Dokumentasi latihan manual testing saya sebagai bagian dari transisi karier ke QA Engineer. Folder ini mencakup test plan formal, test case dengan prioritas berbasis risk analysis (impact × likelihood), bug report profesional, dan exploratory testing charter. Studi kasus difokuskan pada domain fintech untuk relevansi dengan target karier saya.

## Isi Folder

| File | Deskripsi |
|---|---|
| `test-plan-transfer-dana.md` | Test plan formal untuk fitur transfer dana |
| `test-cases-transfer-dana.md` | 10 test case dengan priority & alasan risk-based |
| `exploratory-charter-otp.md` | Exploratory testing charter untuk flow OTP |
| `bug-reports/` | Kumpulan bug report profesional dari aplikasi latihan |

## Teknik yang Digunakan

- STLC (Software Testing Life Cycle)
- Equivalence Partitioning
- Boundary Value Analysis
- Decision Table Testing
- Risk-Based Test Prioritization (Impact × Likelihood)
- Exploratory Testing (Session-Based Charter)

## Konteks

Studi kasus disusun menyerupai fitur aplikasi fintech (transfer dana, top up, registrasi), relevan dengan role QA Engineer yang menjadi target karier saya.
